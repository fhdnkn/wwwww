# نموذج تسجيل الطلاب مع فواتيرك وجوجل شيت

هذا المشروع يحتوي على نموذج HTML لتسجيل الطلاب وإرسال البيانات إلى Google Sheets بالإضافة إلى إنشاء فاتورة دفع عبر خدمة **فواتيرك**.

## الملفات
- `index.html` : واجهة النموذج.
- `style.css` : تنسيق الواجهة.
- `main.js` : منطق إرسال البيانات والدفع.
- `Code.gs` : سكربت جوجل لتخزين البيانات في Google Sheets.
- `App.tsx` : مكون React/TypeScript لنموذج تسجيل متقدم (يحتاج بيئة React).

## الاستخدام
1. أنشئ Google Sheet جديد ثم أضف السكربت الموجود في `Code.gs` داخل Apps Script، بعدها انشره كـ Web App واحصل على الرابط.
2. استبدل قيمة `scriptURL` في `main.js` برابط الويب للسكربت.
3. احصل على مفتاح API من فواتيرك وضعه مكان `YOUR_FAWATERK_TOKEN` في `main.js`.
4. افتح `index.html` في متصفحك لتجربة النموذج.

> ملاحظة: الكود الخاص بوسيلة الدفع هو مثال مبسط وقد يحتاج لتعديلات بحسب وثائق فواتيرك الرسمية.
